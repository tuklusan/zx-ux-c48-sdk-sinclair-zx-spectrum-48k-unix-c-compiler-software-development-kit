**Current specification:** [04-C48 Language Specification Rev 0.11.docx](https://github.com/tuklusan/ZX-UX-The-ZX-Spectrum-48K-Unix-Project/blob/main/docs/04-C48%20Language%20Specification%20Rev%200.11.docx)

This file is only a pointer. The upstream document is authoritative. The documentation in this SDK repository describes the portable host-side C48 compiler and VM environment and does not replace the native ZX-UX language specification.
