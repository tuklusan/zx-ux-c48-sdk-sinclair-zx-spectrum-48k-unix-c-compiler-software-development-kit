# ZX-UX C48 SDK Documentation

This directory contains documentation for the **ZX-UX C48 SDK**, the portable host-side development environment used to build and test C48 software away from a native ZX-UX system.

## Full C48 Language Specification

The complete, normative **C48 Language Specification** is maintained in the upstream **ZX-UX — The ZX Spectrum 48K Unix Project** repository, alongside the native ZX-UX environment for the Sinclair ZX Spectrum 48K.

**Current specification:** [04-C48 Language Specification Rev 0.11.docx](https://github.com/tuklusan/ZX-UX-The-ZX-Spectrum-48K-Unix-Project/blob/main/docs/04-C48%20Language%20Specification%20Rev%200.11.docx)

**Canonical upstream documentation directory:** [ZX-UX Project — docs/](https://github.com/tuklusan/ZX-UX-The-ZX-Spectrum-48K-Unix-Project/tree/main/docs)

The upstream copy is authoritative. The manuals and technical material in this SDK repository describe the SDK environment and its implementation; they do not replace the C48 Language Specification or document the complete native ZX-UX operating environment.
